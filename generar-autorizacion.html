▸ Links cortos — configuración (una sola vez por navegador)

Para que el link sea corto (renuevasmart.com/c/contrato-cliente/#clave) esta página guarda los datos cifrados en el repositorio del sitio. Necesita un token de GitHub: crearlo acá con acceso solo al repositorio renueva-smart-web y el permiso Contents: Read and write (poné vencimiento). El token queda guardado solo en este navegador. Sin token se genera el link largo de siempre.

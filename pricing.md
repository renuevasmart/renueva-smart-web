# Precios — Renueva Smart

Servicio: diseño y rediseño web para servicios profesionales (abogados, notarías, gestorías, inmobiliarias, clínicas dentales y estéticas). Moneda: euros. **Todos los precios son + IVA.** Son rangos orientativos para el proyecto completo, ya publicado. El precio cerrado se da tras ver la web actual del cliente.
Última actualización: 12 de octubre de 2026. Fuente: https://renuevasmart.com/precio-rediseno-web.html

## Antes/después
- Precio: 0 €
- Qué es: un enlace privado a la web rediseñada, navegable y con el contenido real del cliente.
- Compromiso: ninguno. Solo se paga si el cliente decide publicar la web nueva.

## Landing — 1 página
- Precio: 400–650 € + IVA
- Una sola página larga con todo lo importante.

## Web pequeña — 2 a 5 páginas
- Precio: 700–1.200 € + IVA
- Micrositio con navegación: varias páginas cortas.
- Plazo de la web completa publicada: 2 a 3 semanas.

## Web mediana — 6 a 10 páginas
- Precio: 1.200–2.200 € + IVA
- El tamaño de un despacho: una página por área o servicio, equipo y contacto.
- Plazo de la web completa publicada: 3 a 5 semanas.
- No se hacen webs de más de 10 páginas.

## Qué modifica el precio dentro del rango
- Si se parte de cero y hay que estructurar todo el contenido: sube alrededor de un 20 %.
- Si la publica el proveedor del cliente en lugar de Renueva Smart: baja alrededor de un 15 %.
- Si el cliente autoriza usar su web como caso de estudio con reseña: −10 %.
- El alojamiento (incluido si publica Renueva Smart) y los retoques puntuales de fotos o vídeo no cambian el precio.

## Incluido siempre
- Diseño e identidad a medida, sin plantillas prestadas.
- Web adaptada al móvil.
- Contenido real del cliente reordenado, sin inventar nada.
- Formulario de contacto.
- SEO básico en las páginas.
- Dos rondas de ajustes tras la entrega.
- Si publica Renueva Smart: publicación en el dominio del cliente, acompañamiento y alojamiento sin cuotas mensuales.
- Si publica el proveedor del cliente: diseño, archivos y guía de implementación.
- Dominio a nombre del cliente.
